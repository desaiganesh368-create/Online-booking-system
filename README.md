# Online Booking System

A front-end healthcare and doctor appointment booking web application built using **HTML, CSS, and JavaScript**.

This project was created as part of my **Full Stack Web Development learning journey** to practice frontend development, responsive design, forms, JavaScript functionality, and real-world web application structure.

---

## 📌 About the Project

The **Online Booking System** is a web-based application designed to provide users with a simple platform for exploring healthcare services, registering and logging in, viewing doctors, checking doctor availability, selecting a doctor, and booking appointments online.

The application also includes sections for **Traditional Healing** and **Modern Healthcare Services**, bringing different healthcare options together in one platform.

> **Note:** This is an educational and portfolio project built with frontend technologies. It is not intended to be used as a production healthcare system.
